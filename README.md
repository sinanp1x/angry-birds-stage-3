# angry-birds-stage-3

Angry Birds Stage 3 — Introducing Constraint. The next stage in the Angry Birds learning progression, now using Matter.js constraints (Slingshot.js at 1558 bytes). Features Bird, Box, Ground, Log, Pig, and BaseClass with constraint-based physics.

## Tech Stack

- **p5.js** — canvas-based creative coding library
- **p5.play.js** — sprite and collision support for p5.js
- **Matter.js** — 2D physics engine

## How to Run

Open `index.html` in a browser — no build step required. All libraries are vendored in the repo.
